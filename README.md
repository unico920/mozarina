# モザリナ

画像の一部にモザイク・ぼかし・塗りつぶしをかけて、PNG で保存するツールです。
`index.html` 1枚だけで動きます。インストールもサーバーも不要です。

- 画像はブラウザの中だけで処理し、どこにも送信しません
- 外部のライブラリやインターネット接続は使いません

## 使い方

1. `index.html` をダウンロードして、ダブルクリックでブラウザで開きます
2. 画像を読み込みます（次のどれでも OK）
   - 「画像を開く」ボタン、または画面中央をクリックして選ぶ
   - 画像ファイルを画面にドラッグ&ドロップ
   - コピーした画像を Ctrl+V（Mac は ⌘+V）で貼り付け
3. モードを選んで、隠したいところをドラッグで囲みます。離した瞬間にかかります
4. 「保存」で `mozarina-元のファイル名.png` としてダウンロードされます

## モード

| モード | 内容 | 調整 |
|---|---|---|
| モザイク | 四角いブロックに区切って、ブロックごとに平均の色で塗る | 強さ = ブロックの大きさ（4〜64px） |
| ぼかし | なめらかにぼかす | 強さ = ぼかしの半径（2〜40px） |
| 塗りつぶし | 選んだ色でベタ塗りする | 色を選べる（初期は黒） |

- 同じ場所に何度でも重ねてかけられます
- 強さはモードごとに覚えています

### 本当に見られたくない情報は「塗りつぶし」で

モザイクやぼかしは細かい部分を混ぜて薄めているだけなので、条件がそろうと元の文字を推測されることがあります。
名前・住所・お金・パスワードなど、絶対に読まれたくない情報には **塗りつぶし** を使ってください。塗りつぶしは元の情報が画像に一切残りません。

## 透かし

パクリ防止用に、好きな文字（アカウント名など）を画像全体に斜めにくり返して重ねられます。

- 「透かし」の欄に文字を入れると自動でオンになり、すぐ画面に表示されます
- 白・不透明度 20% で、右上がりに敷き詰めます
- 文字の大きさと間隔は画像の大きさに合わせて自動で決まります（Retina のスクショでも見た目が同じ）
- 透かしは保存するときに画像に焼き込まれます。作業中はいつでも文字を変えたりオフにしたりできます
- 入れた文字はそのブラウザが覚えておきます（外には送られません）

## ショートカット

| 操作 | Windows | Mac |
|---|---|---|
| 元に戻す（最大30回） | Ctrl+Z | ⌘+Z |
| 保存 | Ctrl+S | ⌘+S |
| 画像を貼り付け | Ctrl+V | ⌘+V |

## 保存される画像

- 大きさ（解像度）は元の画像のままです。画面で縮小して表示していても小さくなりません
- 透明な部分は透明のまま保存されます
- ファイル名は `mozarina-` + 元の名前から最後の拡張子を外したもの + `.png`
  - 例: `photo.jpg` → `mozarina-photo.png`、`a.b.webp` → `mozarina-a.b.png`
  - 貼り付けた画像など名前が無いときは `mozarina-image.png`

## 対応ブラウザ

Chrome / Edge / Safari / Firefox の最近のバージョン。
読み込める形式は JPG・PNG・WebP など、ブラウザが表示できる画像です。スマホで撮った写真の向き（EXIF）も自動で反映されます。
